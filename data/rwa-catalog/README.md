# ALIVE RWA catalog fixtures

`catalog.demo.json` is a synthetic, dated catalog for deterministic local and
testnet demonstrations. It is **not live market data**, contains no real token
addresses, and conveys no claim on any named real-world instrument.

Every known asset field is mapped to an explicit `DEMO_FIXTURE` source. Unknown
deployment coordinates, feeds, fees, and terms are omitted instead of invented.
Any future snapshot/live catalog must replace the demo provenance with official
issuer, protocol, regulatory, onchain, or Chainlink sources.
